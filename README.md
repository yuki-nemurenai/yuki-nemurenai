## 👋 About

I'm a **DevOps / MLOps Engineer** at [Palex Ltd.](https://palexgroup.com/) with a background in Linux system administration.

I design and operate production infrastructure across **bare metal, virtualized environments, cloud platforms, and Kubernetes** — with a strong focus on automation, reliability, observability, and developer experience.

I'm particularly interested in the intersection of **platform engineering and AI**: using LLMs, agents, MCP, and self-hosted models to automate operational work and make infrastructure easier to operate.

## 🛠️ What I Build

### ☸️ Platform Engineering

- Kubernetes platforms and production workloads
- GitOps with Flux and declarative infrastructure
- Terraform modules and Ansible automation
- Helm, Gateway API and cloud-native networking
- Developer platforms and internal tooling

### 🚀 Delivery & Reliability

- CI/CD pipelines and deployment automation
- Observability with Prometheus, Grafana, VictoriaMetrics and VictoriaLogs
- SRE practices, incident response and operational tooling
- Security automation, secrets management and supply-chain scanning
- High-availability infrastructure and disaster recovery

### 🤖 AI Infrastructure & MLOps

- Self-hosted LLM inference
- AI agents for infrastructure and operations
- MCP servers and tool integrations
- LLMOps / model serving infrastructure
- GPU infrastructure with NVIDIA CUDA and AMD ROCm

### 🌐 Systems & Networking

- Linux and Windows infrastructure
- Bare metal, VMs and cloud environments
- Proxmox and Hetzner
- Networking, routing, VPN and zero-trust infrastructure
- PostgreSQL, Redis, NATS, Kafka and RabbitMQ

---
## 📌 Engineering Principles

> **If it runs twice, automate it.**

- Infrastructure should be reproducible.
- Production changes should be observable.
- Configuration belongs in Git.
- Manual operations should become automation.
- Security should be part of the platform, not an afterthought.
- AI should remove operational toil, not add another dashboard.
